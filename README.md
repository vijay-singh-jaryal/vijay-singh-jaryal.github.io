# Vijay Singh Academic Website

This is a static academic website with a visual structure closely aligned to the supplied Tarun Rambha website reference:

- dark fixed header
- fixed light-grey sidebar below the header
- narrow centred academic content column
- landscape profile image beside the introduction
- responsive mobile navigation

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder while preserving the `assets` directory.
3. Open repository Settings → Pages.
4. Select the main branch and root directory.
5. Save and wait for the public URL.
