M.Tech Thesis

Estimation of Origin–Destination Matrices Using Traffic Counts

Origin–destination matrices describe how travel demand is distributed between zones. The thesis developed an automated framework for estimating these matrices from junction-level turn counts, reducing dependence on expensive and infrequent manual travel surveys.

Study Framework

  • Created a VISSIM digital twin covering 8 junctions, 16 zones, and 7 vehicle classes around the IISc corridor.
  • Used traffic counts from 6 key junctions as observed inputs.
  • Automated simulation runs through a COM-based Python pipeline.
  • Compared MCP, SPSA, and TuRBO estimation approaches.
  • Evaluated results using R², NRMSE, GEH, and attraction-sum deviations.

Key Result

MCP performed best overall. For cars at high-volume junctions, representing approximately 60–65% of network traffic, the method achieved R² values above 0.7 and kept attraction-sum deviations below 20%. SPSA and TuRBO showed substantially larger deviations for several origin–destination pairs.

Tools

Python, VISSIM, COM automation, NumPy, Pandas, optimization and simulation-based estimation.
